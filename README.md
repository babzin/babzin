## About

I'm a software engineer interested in building practical products and understanding the systems that make them work.

My work spans web and mobile applications, backend systems, automation, data analysis and AI-assisted development. I use AI as part of my engineering workflow while staying involved in the code, architecture, debugging and technical decisions.

I also write about software engineering, emerging technology, developer tools and the lessons that come from building.

## Areas I work in

- **Software engineering:** application development, APIs, backend systems and architecture

- **Product building:** turning ideas into usable software and iterating on them

## How I think about engineering

Good software is more than code that runs. It should solve a real problem, handle failure thoughtfully, protect its users and remain understandable as it evolves.

I value clear architecture, deliberate tool choices, maintainable code, practical testing and honest technical communication.
